# Loan Approval Prediction Using Machine Learning

## Project Overview

This project predicts whether a loan application is likely to be approved based on applicant information using Machine Learning classification algorithms.

## Objective

The main objective is to build and evaluate Machine Learning models to predict loan approval outcomes and identify a suitable-performing model.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Joblib
* Google Colab

## Machine Learning Algorithms

* Logistic Regression
* Decision Tree Classifier
* Random Forest Classifier

## Project Workflow

1. Load the loan application dataset.
2. Explore and understand the dataset.
3. Handle missing values and preprocess the data.
4. Encode categorical features.
5. Split the dataset into training and testing sets.
6. Train the Machine Learning models.
7. Evaluate model performance using appropriate metrics.
8. Select the best-performing model based on evaluation results.
9. Save the trained model using Joblib.

## Project Files

* `Loan_Approval_Prediction.ipynb` — Jupyter Notebook containing the project implementation.
* `loan_approval_model.pkl` — Saved Machine Learning model.
* `train_u6lujuX_CVtuZ9i.csv` — Dataset used for training and evaluation.

**Note:** The dataset filename listed above is an example. Replace it with the actual CSV filename in this repository.

## Model Evaluation

The models are evaluated using appropriate classification metrics. The best model is selected based on the evaluation results obtained during experimentation.

## How to Run

1. Clone or download this repository.
2. Install the required Python libraries.
3. Open `Loan_Approval_Prediction.ipynb` in Jupyter Notebook or Google Colab.
4. Run the notebook cells in order.

## Disclaimer

This project is developed for educational and internship purposes. Predictions should not be used as the sole basis for real-world loan approval decisions.
